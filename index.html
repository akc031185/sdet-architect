Plate 45 · a field guide of its own

Whatever tests an organisation already has, rebuilt as one Playwright architecture.

  • Point it at a folder of Selenium in Java, Python, C# or JavaScript, Cucumber features, Postman collections and markdown test plans.
  • It parses all of it into one model, standardises every locator with a confidence score, and generates one Playwright + Playwright MCP project.
  • MIGRATION.md lists every line it could not convert with its source file:line. The human work is the TODO list, not the reading.

What "agent" means here

Scoped automation, not a chat assistant.

  • Regex and line-based parsers only: no AST libraries, no Java, Python or .NET toolchain needed.
  • Byte-for-byte deterministic with LLM_PROVIDER=none; a local model may only add suggestion: comments next to TODOs.
  • Findings in five categories (locator, conversion, flakiness, duplication, quality) and one artifact row per generated file.
  • A preview route converts a single file with no disk and no database.
"One job, one contract — composable, scriptable, and boring by design."

Standardising what already exists

  • Most organisations start from Selenium nobody has run, a .feature file whose steps drifted, and a Postman collection with the real expectations in pm.test scripts.
  • The SDET Architect inventories all of it and emits one architecture and one MIGRATION.md.
  • Every line a human still has to think about carries a TODO(sdet-architect) comment with its source file:line.
